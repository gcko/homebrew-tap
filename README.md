# gcko/homebrew-tap

Homebrew formulas for [Cortado](https://github.com/gcko/Cortado), a statusline for Claude Code.

The Cortado formula is on its way. Until it lands, install Cortado from source: see the [Cortado README](https://github.com/gcko/Cortado#install).

Once it is published:

```bash
brew install gcko/tap/cortado
cortado setup
```
